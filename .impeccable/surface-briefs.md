# Surface Briefs — CampusSphere 前端视觉重设计

> 依据 impeccable new-work 流程落盘。视觉世界 = 登机牌 · 航站屏（见 DESIGN.md）。模式全局 **Operate**（可扫读、一致、原生预期 > 表达），首页为中枢骨架、后台为调度控制板。每面给出「成功画面 / 关键约束 / 世界签名（本轮已落地）」。

## shell — App / Navbar / 守卫 / ReportModal
- **成功画面**：用户随时知道自己在哪个航站区，能一步抵达任意模块；加载不白屏、受保护页守卫态清晰、举报在任何场景可用且风格统一。
- **约束**：移动底部栏（信息板/列表/搜索/我的）+「更多」抽屉收纳次级模块；桌面顶部栏；登录/后台登录不渲染导航；导航项 mono 大写、激活项用模块区域色身份。
- **世界签名**：底部 5 格导航 + 更多抽屉；Suspense「正在登机...」；ReportModal 已对齐设计系统（error 语义 / ink 按钮 / Esc 关闭 / focus 管理）。

## auth — Login / AdminLogin
- **成功画面**：用学生凭证快速进入；验证码像扫描码/确认码一样可见可核；第三方登录状态不误导。
- **约束**：凭证式表单、验证码呈现为确认码块、状态明确；未接入的第三方入口明确禁用而非死控件。
- **世界签名**：OAuth 深品牌色（微信 #0B7A3B / QQ #0E6FA8，5.44:1）；微信/QQ 为「未接入」禁用态 + 说明文案。

## home — HomePage
- **成功画面**：第一屏 = 全局「找」查询台 + 多块实时信息板；一眼看到板上有什么变动、抓到登机口。
- **约束**：多块信息板（二手最新/热搜/课程/食堂/搭子），每行 = 关键序 + tabular；变更行 alert 保持；底部栏。
- **世界签名**：核心功能矩阵 + 信息板（Board）；最新物品首行 changed 黄色点亮；搭子列头「动作」；mono 眉题系统。

## market — MarketList / Detail / Publish
- **成功画面**：找到想买的/想卖的并发出联系（登机口）；价格/分类/卖家一眼可扫；交易可信不冒充。
- **约束**：闲置 = 登机牌（价格 tabular/分类/卖家/联系）；列表 = 信息板；发布 = 强引导凭证表单；无图用占位不冒充真实照片。
- **世界签名**：详情页「交易登机牌」PassCard（ITEM 编号/4 段/扫码块/撮合 CTA）；假图已替换为 ImagePlaceholder；主按钮 ink 统一。

## course — CourseSearch / Detail / Review
- **成功画面**：选课前看口碑（给分/作业量/考核）、评课有据可查；AI 摘要如实标注不夸大。
- **约束**：课程 = 凭证（名称/教师/评分）；评价 = 板；学部/院系分级筛选；评分 tabular。
- **世界签名**：详情页「选课登机卡」PassCard（CS 编号扫码块/评课 CTA）；AI 区用 surface 而非 alert（信号纯度）；分类 pill 用 zone-course。

## canteen — CanteenList / Stall
- **成功画面**：知道此刻去哪个食堂、哪个档口、什么招牌；口味/评分一眼可扫。
- **约束**：档口/菜品 = 凭证 + 板；口味/评分 tabular；学部/类型筛选；标签不伪造数据。
- **世界签名**：CANTEEN 航站屏眉题 + 4 食堂卡片（营业时间/楼层/评分 4.7/招牌菜品）；「口碑力推」→「档口招牌」去伪；主 CTA ink 统一。

## community — TeammatePost / ShareFeed / JobList
- **成功画面**：找到搭子/资料/兼职并发出请求（登机口动作）；流转清晰。
- **约束**：招募/共享/兼职 = 凭证；申请 = 登机口动作；假 URL/假数据清除。
- **世界签名**：TEAM·组队登机口 / SHARE·资源库 / JOB·勤工登机口 眉题；主按钮 ink 统一；分享假 URL 已清空。

## messaging — MessageCenter
- **成功画面**：会话实时、新消息不遗漏；断线/重连状态明确。
- **约束**：会话 = 实时重排板；新消息 = alert 保持；WebSocket 在线/断开态明确。
- **世界签名**：MESSAGE 眉题 + 会话列表（空态「暂无活跃会话」）；「双向加密」→「加密传输」如实；头像占位。

## profile — UserProfile
- **成功画面**：个人信任背书（认证/信用/发布记录）一眼可见；资料可维护。
- **约束**：一卡通式个人凭证卡（个人信息 + 关键数据）；第三方绑定状态明确。
- **世界签名**：已认证学生徽标 + 4 Tab（资料/安全/发布/收藏）+ 资料表单；OAuth 深品牌色达标。

## admin — AdminDashboard
- **成功画面**：调度员一眼见待处理工单（举报/用户治理）、快速处理、变更保持；看板数据一目了然。
- **约束**：调度控制板；举报/工单 = 需处理的行，alert 保持；发丝排版；recharts 独立懒加载。
- **世界签名**：ADMIN GATE 网关守卫 → 9 Tab 调度板；待处理举报用 alert 徽标（非 error 红大字）；概览指标卡 + 图表。
