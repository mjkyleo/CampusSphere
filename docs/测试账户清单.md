## 3. 如何重建环境

```bash
# 1. 确保后端服务已启动（start-dev.bat）
# 2. 创建 15 个账户（幂等）
cd backend
python scripts_seed_users.py

# 3. 灌入全功能数据（仅首次；已有数据会跳过）
python scripts/seed_full_data.py

# 4. 运行真实用户全功能 E2E 测试
cd ../e2e
npx playwright test --config=playwright.dev.config.ts
```

> 如需完全重灌：删除 `backend/dev.db`，重启后端（会自动建表 + 引导管理员），再按上面 2→3→4 顺序执行。

## 6. 注意事项

1. **认证限流**：登录/注册 10 次/分钟（`AUTH_RATE_LIMIT_PER_MINUTE=10`），通用接口 120 次/分钟（`RATE_LIMIT_PER_MINUTE=120`）。E2E 测试通过「单 context + 减少登录次数 + 直查 DB」绕开限流。
2. **验证码**：开发模式 `EXPOSE_VERIFICATION_CODE=true` + `CAPTCHA_ENABLED=false`，点"获取验证码"后验证码自动填入输入框，无需真实邮件/短信。
3. **数据库位置**：`backend/dev.db`（SQLite）。删除该文件会丢失所有账户和数据。
4. **E2E 输出目录**：配置在系统临时目录（`%TEMP%/cs-e2e-dev`），避免与 workspace 的删除保护冲突。
