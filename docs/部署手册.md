# 校园生活平台（Python 重写）部署手册

> 适用对象：运维 / 校方平台管理员
> 目标：单校实例，"一份代码 + 一份 school.yaml" 一键上线

## 1. 组件清单

| 组件 | 版本 | 作用 |
|------|------|------|
| FastAPI 应用 | Python 3.12 | 业务 API + WebSocket |
| Celery Worker | 同运行时 | 邮件 / 通知 / 搜索同步（**2026-09-05 实测：仅 email 队列有真实调用方**） |
| PostgreSQL | 16 | 主数据库 |
| Redis | 7 | 缓存 / 限流 / 黑名单 / WS 广播 / Celery Broker |
| MinIO | 最新 | 对象存储（S3 兼容） |
| Meilisearch | v1.11+ | 中文搜索 |
| Nginx | 1.25+ | TLS / 路由 / 限流 / 静态资源 |

## 2. 方式一：Docker 一键起（推荐）

```bash
# 1) 准备学校配置
cp config/school.yaml config/school.yaml.bak
#   修改 school_name / oauth / minio / meilisearch 等字段

# 2) 准备部署环境变量
cp deploy/.env.example deploy/.env
#   修改 SECRET_KEY、DB_URL、MINIO_*/MEILI_* 等

# 3) 启动（自动执行 alembic upgrade head）
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d

# 4) 验证
curl http://localhost/health
# 先用网关密钥换取短时令牌（网关密钥来自部署配置 admin.gateway.key / ADMIN_GATEWAY_KEY）
GATEWAY_TOKEN=$(curl -s http://localhost/api/admin/discover -X POST -H 'Content-Type: application/json' \
  -d '{"gateway_key":"<部署下发的网关密钥>"}' | python -c "import sys,json;print(json.load(sys.stdin)['data']['gateway_token'])")
# 再携带网关令牌登录（账号密码来自 admin.bootstrap / ADMIN_BOOTSTRAP_*）
curl http://localhost/api/admin/login -X POST -H 'Content-Type: application/json' \
  -H "X-Admin-Gateway: $GATEWAY_TOKEN" \
  -d '{"username":"<admin.bootstrap.username>","password":"<admin.bootstrap.password>"}'
```

前端静态资源在 build 后挂载到 `nginx:/usr/share/nginx/html`（挂载路径见 `docker-compose.yml` 的 `./frontend/dist`）：
```bash
cd frontend && npm install && npm run build
```

## 3. 方式二：裸机 / venv 启动（开发 / 轻量）

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env            # 默认 SQLite，零依赖
uvicorn app.asgi:app --host 0.0.0.0 --port 8000
# 另开终端：Celery Worker
celery -A app.tasks.celery_app.celery_app worker --loglevel=info
```

## 4. 默认管理员（配置下发，非硬编码）

应用首次启动会按 `config/school.yaml` 的 `admin.bootstrap` 段（`username` / `password` / `min_length`）自动注入引导管理员：
- 用户名、密码均由部署配置下发（环境变量 `ADMIN_BOOTSTRAP_USERNAME` / `ADMIN_BOOTSTRAP_PASSWORD` 可覆盖）。
- 生产环境若网关密钥或引导密码过弱，`lifespan` 启动期会 **fail-fast 直接退出**，强制部署方配置强口令。
- 管理员登录还需由网关密钥（`admin.gateway.key` / `ADMIN_GATEWAY_KEY`）换取的短时令牌，详见第 1 节验证示例。
- 修改密码：登录后台后在管理界面操作，或更新 `admin_users` 表。

## 5. 多校复制

复制部署 = 复制 `config/school.yaml` + 一份 `.env`（不同域名 / OAuth 密钥 / 存储桶），其余代码完全一致。Nginx 按域名路由到对应实例即可。

## 6. 运维要点

- 限流：Nginx `limit_req` + 应用内基于 Redis 的令牌桶（默认 120 次/分钟/IP）。
- 日志：structlog 输出 JSON 到 stdout，由容器日志采集。
- 监控：Prometheus 抓取 `/metrics`，Grafana 导入 `deploy/grafana/dashboards/*.json`。
- 文件上传：默认 20MB（Nginx `client_max_body_size`）。
- 搜索：首次使用需 Meilisearch 在线；离线时自动回退 DB 模糊查询。

## 7. 故障排查

| 现象 | 排查 |
|------|------|
| 启动报数据库连接失败 | 检查 `.env` 中 `DB_URL` 与数据库可达性 |
| 登录后 401 | 检查 `SECRET_KEY` 是否一致；Redis 黑名单是否误杀 |
| 搜索无结果但数据库有数据 | 检查 Meilisearch 是否在线（**注意：search_sync Celery 任务当前未接线，不会自动同步**；查询自动回退 SQL LIKE） |
| 文件上传 413 | 调整 Nginx `client_max_body_size` |
| WS 连接失败 | 确认 Nginx `/ws` 已配置 `Upgrade/Connection` 透传 |
